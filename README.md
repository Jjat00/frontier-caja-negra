# frontier-caja-negra

Reto 2 (La caja negra) del AI Builders Hackathon Frontier BOG / 26 (Lab10, 2026-10-10).

Un servicio sin documentación recibe mensajes por HTTP y responde. Aquí está el reemplazo que responde
exactamente igual, la especificación y el log de experimentos con los que se descubrió su comportamiento.

- `MATERIAL.md`: enunciado y contrato entregados por la organización.
- `pruebas/ejemplos.jsonl`: 20 requests de ejemplo grabados por la organización.
